# Parts & Parcel AI Context

Place these files in the project repository as:

```text
docs/
├── PROJECT_CONTEXT.md
└── AI_RULES.md
```

`PROJECT_CONTEXT.md` contains the product/domain/workflow decisions.

`AI_RULES.md` contains instructions for AI coding assistants.

Before making substantial architectural changes, instruct the IDE assistant to read both files and inspect the current codebase.
